# Tables & QR codes

You do **not** add tables in Supabase.  
Each table is only a link:

`https://coffee-shop-order-olive.vercel.app/order?table=1`  
… through `?table=30`

**Print all QR codes:**  
https://coffee-shop-order-olive.vercel.app/qr  

1. Open that page  
2. Set count to 30 (default)  
3. Click **Printo / Ruaj PDF**  
4. Print stickers or cards and put on tables
